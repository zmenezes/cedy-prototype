# Cedy: protótipo navegável

Protótipo clicável do aplicativo Cedy (marketplace de antecipação de recebíveis), para validação.

**Acesso:** https://zmenezes.github.io/cedy-prototype/

## Como usar

1. Na tela de entrada, escolha um perfil de demonstração (Cedente, Financiador, Originador, Subparceiro, Sacado, Mesa Cedy ou Superadmin).
2. Informe qualquer senha e, se pedido, o código de dois fatores `123456`.
3. Navegue pelo menu. O relógio da demonstração é simulado e pode ser controlado pelo painel de demonstração (menu do avatar).

## O que é importante saber

- **Dados fictícios.** Empresas, pessoas, valores e documentos são inventados.
- **Sem integrações reais.** Banco, assinatura, consultas cadastrais e IA são simulados.
- **Os dados ficam no seu navegador** (localStorage). Nada é enviado a um servidor, e as alterações de uma pessoa não aparecem para outra.
- Para restaurar os dados de demonstração: acrescente `?reset=1` ao endereço, ou use o painel de demonstração.
- Galeria de componentes: `#/ds`.

As regras regulatórias exibidas são premissas de modelagem ainda não validadas por especialista.
